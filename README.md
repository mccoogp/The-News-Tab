# The News Tab

A Chrome extension that puts your news feeds and daily games in the browser's side panel. It pulls headlines from RSS feeds, ranks them by recency and keywords you choose, and organizes them into topic tabs. Each user gets their own set of topics, and there is also a Games page with links to daily puzzles.

## Instructions

Go to the options page to edit users and feeds. Set shortcuts to open the extension, switch users, and switch topics.

Default shortcuts (Command instead of Ctrl on Mac):

- **Ctrl+Shift+K**: open the panel
- **Ctrl+Shift+L**: switch user
- **Ctrl+Shift+O**: switch topic

To change them, go to `chrome://extensions/shortcuts`.

## Install

1. Download or clone this repository.
2. Go to `chrome://extensions` and turn on Developer mode.
3. Click **Load unpacked** and select the extension folder.
